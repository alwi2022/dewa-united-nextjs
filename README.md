# Dewa United Digital Platform Concept

An independent Next.js concept for a unified Dewa United experience across football, basketball, esports, editorial content, fixtures, video, and merchandise.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm start
```

## Deployment

The Vercel project is linked as `dewa-united-digital-concept`. Run `npx vercel@latest deploy` for a new preview deployment, or connect a Git repository for branch previews.

## Future platform work

Potential next phases include a news and media CMS, fixtures and standings, ticketing, ecommerce, membership, administration, analytics, and SEO.

This repository is an independent working concept and does not represent an official Dewa United website.
